# AbdEX — B2B-площадка грузоперевозок

Веб-платформа по ТЗ‑ABDEX‑2026‑01: заявки, предложения перевозчиков, сделки с неизменяемым снапшотом условий,
документооборот с простой электронной подписью, чат сделки, трекинг рейса, биллинг платформенного
вознаграждения с отчётом по ПВД №14, KPI для технопарка, антифрод, админка и публичный API.

Стек по ТЗ: **Python 3.11, FastAPI, PostgreSQL, SQLAlchemy 2.0, Alembic, Jinja2** (серверный рендеринг,
интерфейс на русском и казахском, адаптивная вёрстка от 360 px, PWA для водителя).

> Существующий MVP загружается отдельно, инструкция в **[UPLOAD_MVP.md](UPLOAD_MVP.md)**.

## Быстрый старт

### Локально (SQLite, без установки БД)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

Откройте <http://localhost:8000>. При первом запуске создаётся база `var/abdex.db` и демо-данные.

### Docker (PostgreSQL + отдельный фоновый обработчик)

```bash
cp .env.example .env
docker compose up --build
```

Миграции применяются автоматически (`alembic upgrade head`).

## Что реализовано

Ядро Цикла 1 и заметная часть Цикла 2. Статус по каждому требованию ТЗ: [docs/requirements-status.md](docs/requirements-status.md).

- **Статусная модель** (раздел 6): единый сервис переходов `app/modules/orders/flow.py`, декларативная таблица,
  история (кто, когда, откуда, куда, IP, устройство), откат только менеджером, таймеры с идемпотентностью.
- **Роли и права** (раздел 5): пользователь ↔ компании через членство с ролью, переключение компаний без
  повторного входа, проверка «роль + принадлежность» в каждом запросе, запрет по умолчанию (тест проверяет,
  что у каждого маршрута есть политика доступа).
- **Заявки → предложения → сделка**: версионирование заявки, ограниченная карточка для перевозчика до акцепта,
  торг со встречными ценами, атомарный акцепт (блокировка строки, уникальный ключ, ключ идемпотентности),
  снапшот условий с SHA‑256, допсоглашения только с акцептом второй стороны, замена водителя или ТС только
  с подтверждением клиента.
- **Документы**: генерация PDF по версионируемым шаблонам (кириллица), сквозная нумерация, простая ЭП кодом
  с фиксацией времени, IP и хеша, загрузка сканов с проверкой содержимого и антивирусом, досье сделки (PDF + ZIP).
- **Биллинг**: тарифы (фикс 35 000 ₸ / % / комбинированный, мин/макс), начисление по событию «сделка
  оформлена», автоматические счёт и акт с формулировкой по FR‑PVD‑03 (запрещённые формулировки блокируются),
  неизменяемые финансовые записи и сторно, сверка по выписке, контроль задолженности, отчёт «Доходы в разрезе ПВД»
  в XLSX и PDF.
- **ИБ**: argon2id, политика паролей, TOTP‑2FA (SMS как резерв), ротация сессии при входе, тайм‑ауты, CSRF,
  строгий CSP без inline‑скриптов, rate limiting, подписанные короткоживущие ссылки на файлы, журнал аудита только
  на добавление (ORM + триггеры PostgreSQL), маскирование ПДн в логах, раздельные согласия.
- **Антифрод**: дубли ИИН/госномера/IBAN/БИН, ТС или водитель чужой компании, одно ТС в параллельных сделках,
  скоринг риска при акцепте с обязательной ручной проверкой, детект контактов в тексте до акцепта.
- **Водитель / PWA**: чек-поинты одной кнопкой, фото, геопозиция только по согласию и на время рейса,
  офлайн‑очередь без дублей, service worker.
- **Админка**: модерация заявок и верификации (очередь с SLA), споры, компании и ограничения, антифрод‑очередь,
  финансы, KPI с фиксацией на отчётную дату, справочники, шаблоны с предпросмотром, фиче‑флаги, настройки,
  журнал аудита, журнал интеграций.
- **API v1**: `/api/v1/…`, OpenAPI на `/api/docs`, ключи компании со scope и сроком, единый формат ошибки,
  ключ идемпотентности, курсорная пагинация, отказ от неизвестных полей.

## Структура

```
app/
  core/            безопасность, деньги, i18n, аудит, хранилище файлов, rate limit, ошибки
  modules/         доменные модули: accounts, fleet, orders, bids, deals, documents, chat,
                   notifications, billing, calc, analytics, support, platform, integrations
  web/             HTTP-слой: маршруты кабинетов, админки и API, проверка прав
  templates/       Jinja2 (весь текст через переводы app/i18n/ru.json, kk.json)
  static/          CSS-библиотека компонентов, JS (прогрессивное улучшение), PWA
alembic/           миграции (обратимые)
tests/             юнит, сквозные и проверки безопасности
docs/              архитектура, ADR, метрики, статус требований, ИБ
scripts/           загрузка MVP, entrypoint контейнера
```

## Тесты

```bash
pytest -q                                                   # SQLite
TEST_DATABASE_URL=postgresql+psycopg://user:pass@localhost/abdex_test pytest -q   # PostgreSQL через миграции
```

CI (`.github/workflows/ci.yml`) запускает линтер, тесты на SQLite и PostgreSQL, проверку синхронности миграций,
bandit, pip‑audit и gitleaks.
