# Архитектура

Модульный монолит на FastAPI. Фоновые обработчики и сервис интеграций вынесены отдельно (раздел 26 ТЗ).

```
 Браузер / PWA водителя / Telegram / партнёры по API
            │
   обратный прокси + WAF (TLS, HSTS, rate limit периметра)
            │
   ┌────────┴───────────────────────────────────────────┐
   │ FastAPI (app/main.py)                              │
   │  web/ — HTTP-слой: маршруты, CSRF, проверка прав    │
   │  modules/*/service.py — бизнес-логика              │
   │  modules/*/models.py — SQLAlchemy 2.0              │
   │  core/ — безопасность, деньги, i18n, аудит, файлы  │
   └────────┬───────────────┬───────────────┬───────────┘
            │               │               │
      PostgreSQL     объектное хранилище   адаптеры интеграций
   (триггеры append-only)  (локально: var/storage)  (карты, реестры, SMS, e-mail, Telegram)
            │
   app/worker.py — таймерные переходы, outbox уведомлений, сроки документов, задолженность
```

## Принципы
- **Статусы** меняет только `orders/flow.py`. Остальные модули подписываются на событие `order.status_changed`
  через `core/events.py`: чат пишет системные сообщения, биллинг начисляет вознаграждение.
- **Деньги** хранятся целым числом в минорных единицах (BigInteger) вместе с кодом валюты. Округление
  выполняется в одном месте, `core/money.round_minor`.
- **Время** хранится в UTC (`AwareDateTime`) и отображается в часовом поясе пользователя.
- **Неизменяемые таблицы** (снапшоты, начисления, платежи, аудит, история статусов, подписи, сообщения):
  запрет UPDATE и DELETE в ORM (`db.AppendOnly`) и триггером в PostgreSQL (миграция 0002).
- **Сессии** хранятся на сервере (таблица `user_sessions`), в cookie лежит случайный токен, в БД только его HMAC.
  Сам процесс приложения состояния не хранит.
- **Файлы** лежат под ключом, который генерирует система. Выдаются только через приложение по подписанной
  ссылке на 5 минут, права проверяются при каждом запросе.
- **Интеграции** наследуются от `integrations/base.Adapter`: таймаут, повторы с растущей паузой, размыкатель
  цепи, кэш, журнал `integration_calls`. В разработке и тестах вместо реальных сервисов работают имитаторы.

## Что заменить при выходе в промышленную эксплуатацию
| Компонент | Сейчас | Production |
|---|---|---|
| Rate limit | в памяти процесса | Redis (тот же интерфейс `core/ratelimit.py`) |
| Хранилище файлов | локальный диск | S3-совместимое хранилище в РК (`core/storage.LocalStorage` → S3) |
| Антивирус | сигнатура EICAR | ClamAV (`AntivirusAdapter.scan`) |
| SMS / e-mail / Telegram | лог и `/dev/outbox` | реальные провайдеры (`integrations/adapters.py`) |
| Маршрутизация | расчёт по координатам городов | картографический сервис |
| Реестры | имитатор | коммерческий источник, затем ГБД ЮЛ/ФЛ через ШЭП (GOV-R-01) |
