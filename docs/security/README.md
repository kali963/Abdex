## Журнал исправлений безопасности

| Дата | Что найдено | Исправление |
|---|---|---|
| 2026-10 | `/dev/outbox` на публичном демо показывал всем SMS-коды и ссылки сброса пароля | Показываются только сообщения текущего пользователя; без входа — ничего |
| 2026-10 | IP брался из `X-Forwarded-For` без проверки — обход лимитов попыток входа | Заголовок учитывается только при `TRUST_PROXY=true`; uvicorn без `--proxy-headers *` |
| 2026-10 | Тексты SMS (с кодами) писались в журнал сервера (SEC-LOG-05) | В журнал попадает только канал и замаскированный адресат |
| 2026-10 | Открытый редирект по заголовку Referer в админке | Только внутренние пути (`safe_next`) |
| 2026-10 | Сотрудник мог открыть сделку по кабинетному URL без записи в аудит | Доступ сотрудников к сделкам только через `/admin/deals/…` (с аудитом) |
| 2026-10 | Нет ограничения размера тела запроса; «бомба распаковки» изображений | 413 при превышении лимита; `MAX_IMAGE_PIXELS` |
| 2026-10 | Повтор перехваченного TOTP-кода в пределах окна | Сохраняется последний использованный шаг, повтор отклоняется |
| 2026-10 | Небезопасные cookie на HTTPS-демо, нет COOP/CORP, `no-store` не на всех личных страницах | `Secure` на Vercel, заголовки COOP/CORP, `no-store` для всех страниц с сессией |
| 2026-10 | Заголовок `X-Request-ID` попадал в логи без очистки (инъекция в журнал) | Допустимы только `[A-Za-z0-9._-]` |
| 2026-10 | Сравнение API-ключа не за постоянное время | `hmac.compare_digest` |
| 2026-10 | Офлайн-кэш рейсов оставался на телефоне после выхода | Выход очищает кэш service worker и офлайн-очередь |
