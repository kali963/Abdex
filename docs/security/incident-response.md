# План реагирования на инциденты: черновик (SEC-IR-01/02)

1. **Обнаружение:** оповещения мониторинга, сообщения пользователей, канал security@abdex.kz.
2. **Классификация:** критичный (утечка ПДн, компрометация админ-аккаунта), высокий, средний.
3. **Локализация:** отзыв сессий пользователя (`/admin/users` → блокировка), отключение интеграции фиче-флагом,
   ротация `SECRET_KEY` (при этом завершаются все сессии и ссылки).
4. **Сохранение доказательств:** выгрузка `audit_log`, `integration_calls`, логов с `request_id`. Таблицы аудита
   изменить нельзя.
5. **Уведомление:** при утечке ПДн уведомить затронутых субъектов и уполномоченный орган в установленные сроки.
6. **Разбор:** без поиска виноватых, с перечнем изменений и сроками.
