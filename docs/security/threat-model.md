# Модель угроз (STRIDE): черновик

Границы доверия: браузер ↔ обратный прокси ↔ приложение ↔ PostgreSQL / хранилище / внешние сервисы.

| Угроза (раздел 33) | STRIDE | Контрмеры в коде |
|---|---|---|
| Фиктивный перевозчик по чужим реквизитам | S | Уровни L0–L3, модерация, сверка с реестром, дубли БИН/ИИН/IBAN → антифрод |
| Захват аккаунта | S | argon2id, лимит попыток, блокировка, TOTP, уведомление о новом устройстве |
| Подмена банковских реквизитов | T | Код по второму каналу, уведомление владельцам, 24 часа охлаждения, аудит |
| Передача сделки третьему перевозчику | R/T | Фиксация исполнителя, замена только с подтверждением клиента, алерты на чужое ТС или параллельные сделки |
| Доступ к чужим объектам по ID (IDOR) | I | Проверка принадлежности в каждом запросе, 404 вместо 403, тесты |
| Массовая выгрузка | I | Rate limit, аудит выгрузок, ограниченные роли |
| Злоупотребления сотрудника | I/E | Отдельная админка, минимальные права, аудитор без доступа к содержимому, причина при просмотре контактов |
| Вредоносный файл | T/E | Белый список по содержимому, антивирус, пересохранение изображений, выдача с sandbox-CSP |
| Уязвимые зависимости | E | Зафиксированные версии, pip-audit в CI |
| Отказ в обслуживании | D | Rate limit (в production Redis + WAF на периметре) |
| Подделка документа после подписания | T/R | SHA-256 при генерации и загрузке, проверка хеша при подписи, неизменяемые подписи |
