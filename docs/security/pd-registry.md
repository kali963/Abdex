# Реестр обработки персональных данных: черновик (SEC-CMP-02)

| Категория | Субъект | Цель | Основание | Где хранится | Срок | Получатели |
|---|---|---|---|---|---|---|
| ФИО, телефон, e-mail | пользователь | регистрация, вход | согласие «registration» | `users` | срок жизни аккаунта + N лет | — |
| ИИН, данные ВУ | водитель | верификация | согласие «verification» | `drivers`, документы в хранилище | пока действует допуск + N лет | модератор |
| Сканы документов | представитель компании, водитель | верификация | согласие «verification» | объектное хранилище | до замены документа + N лет | модератор |
| Геопозиция | водитель | трекинг рейса | согласие «geolocation», только на время рейса | `checkpoints` | N лет (доказательная база сделки) | стороны сделки |
| IP, устройство | пользователь | безопасность | законный интерес / требования ИБ | `user_sessions`, `audit_log` | не меньше 12 месяцев | аудитор ИБ |

Сроки (N) утверждает ответственный за обработку ПДн. Данные хранятся на территории РК (NFR-LAW-01).

## Реестр в системе (SEC-DAT-10/11)

Рабочий реестр ведётся в самой системе: `/admin/processing` (права `admin.settings`), публичная часть показывается
в политике обработки ПДн (`/legal/privacy`). У записи есть цель, категории данных, основание, получатель, признак
трансграничной передачи со странами и мерами защиты, срок хранения и адаптер интеграции.

Интеграция, которая отправляет персональные данные за пределы платформы (SMS, e-mail, push, Telegram, реестры,
биометрия), работает только пока в реестре есть активная запись с её адаптером. Если запись остановить, передача
прекращается сразу, а вызов попадает в журнал интеграций со статусом `not_registered`. Трансграничную запись нельзя
сохранить без стран и мер защиты.

| Данные | Где | Защита |
|---|---|---|
| ИИН, телефон, номер ВУ водителя; IBAN | `drivers`, `bank_accounts` | AES-256-GCM на уровне приложения, поиск по слепому индексу (HMAC), ключи из хранилища секретов |
| Биометрия | `biometric_checks` | хранится только результат; исходные снимки удаляются через `biometrics.image_ttl_hours` (24 ч) и сразу при отзыве согласия |
| Данные компаний | 12 таблиц | RLS в PostgreSQL как второй рубеж после проверки в приложении |
| Копии базы для разработки | любая не боевая среда | обязательное `python -m app.cli anonymize --confirm`; без него среда не запускается на копии боевой базы |
