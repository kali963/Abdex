# ADR-0001: модульный монолит на FastAPI + Jinja2

**Контекст.** MVP уже работает на FastAPI, PostgreSQL, SQLAlchemy 2.0 и Jinja2. Команда небольшая.
За 24 месяца нагрузка вырастет до ~2 500 участников и ~2 000 сделок, ТЗ требует десятикратный запас.

**Решение.** Модульный монолит с доменными модулями (`app/modules/*`). Межмодульные вызовы идут через сервисы
и события, рендеринг серверный (Jinja2), JS добавляет удобства и не обязателен для работы. Фоновые задачи
выполняет отдельный процесс `app.worker`.

**Альтернативы.** Микросервисы: избыточная сложность для такой нагрузки. SPA: тяжелее для мобильного трафика
в регионах, решение откладывается до Ц2–Ц3.

**Последствия.** Масштабирование горизонтальное (приложение не хранит состояние). Модули можно выделить в сервисы,
когда понадобится.
