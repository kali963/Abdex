# ADR-0002: единый сервис статусов с декларативной таблицей переходов

**Контекст.** Статусная модель — ядро системы (раздел 6). Нелегальный переход должен давать 409, а не тихо менять данные.

**Решение.** Таблица `TRANSITIONS` в `orders/flow.py` задаёт для каждой пары статусов разрешённых акторов и обязательность
причины. Переход выполняет только `flow.transition()`: он блокирует строку (`SELECT … FOR UPDATE`), пишет `status_history`
и публикует событие. Тест сверяет таблицу с ТЗ.

**Отклонение от ТЗ.** Добавлен переход `bidding → cancelled` для клиента («отмена до назначения исполнителя»), потому что
формулировка ТЗ покрывает и статус сбора предложений.
