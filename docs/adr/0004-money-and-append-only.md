# ADR-0004: деньги в минорных единицах, финансовые записи только на добавление

**Решение.** Все суммы хранятся в BigInteger в тиынах (центах) вместе с кодом валюты. Правило округления одно:
ROUND_HALF_UP в `core/money.round_minor`. Начисления, платежи, снапшоты и аудит никогда не изменяются;
ошибку исправляют сторнирующей записью (`storno_of_id`). Идемпотентность начисления обеспечивает уникальное
поле `accruals.event = "deal_formalized:<deal_id>"`.
