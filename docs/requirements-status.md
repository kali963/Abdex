Исправлено: лимит попыток 2FA; одинаковое время ответа при входе; доверенный адрес клиента через `TRUSTED_PROXY_HOPS`; сессия без второго фактора не даёт доступа; работа от имени пользователя — только по списку разрешённых действий; API-ключ не работает для заблокированной компании; проверка ЭЦП (сроки, OCSP, отзыв, владелец); защита от формул в CSV/XLSX; ограничения размера при импорте; доступ к файлам досье, биометрии и документам вознаграждения; смена исполнителя — только свой транспорт; цены дополнений и встречных предложений в пределах сделки; повторные платежи не задваиваются; блокировки строк в очередях; лимит размера запроса; даты по времени Алматы.
